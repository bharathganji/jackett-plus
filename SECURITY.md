# Security Policy

## Supported Versions

Only the latest release of `jackett-plus` is actively supported with security patches and vulnerability fixes.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :x:                |

---

## Reporting a Vulnerability

The Jackett Plus team takes security and privacy very seriously. We appreciate your efforts to responsibly disclose any potential vulnerabilities.

### Disclosure Process
- **Do NOT create public GitHub issues or discussions for security vulnerabilities.**
- Report vulnerabilities privately through [GitHub Security Advisories](https://github.com/bharathganji/jackett-plus/security/advisories/new).
- Alternatively, you can message the lead maintainer directly via GitHub ([@bharathganji](https://github.com/bharathganji)).

### What to Include in Your Report
To help us investigate and triage the issue efficiently, please provide:
1. Description of the vulnerability.
2. Steps to reproduce or proof-of-concept (PoC).
3. Potential impact (e.g., token leakage, network bypass, container escape).
4. Suggested remediation if known.

---

## Response Timeline
- **Initial Response:** Within 48 hours acknowledging receipt of the report.
- **Assessment & Triage:** Within 5 business days confirming severity and remediation plan.
- **Fix & Public Advisory:** Coordinated release once a patched container/version is validated.
